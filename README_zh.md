# 包含天空图像、辐照度、再分析与预报的26个月光伏多模态数据集

这是覆盖 2024-01-01 至 2026-02-28 的预发布数据包。

## 已核验内容

- 122,213 张全天空图像，分为 26 个无损 JPEG XL 月度分卷
- 96,481 条唯一图像—功率配对
- 固定时间顺序划分：训练 65,837、验证 17,032、测试 13,612
- 500 张人工复核图像和 500 个语义掩膜
- 6,405 个主要的 15 分钟、1.5 kW 坡度事件
- 18,960 个 ERA5 小时和 1,429 个可用 IFS 运行

JPEG XL 分卷可将全部原始 JPEG 按字节完全恢复。使用随包恢复脚本和 `djxl --reconstruct_jpeg`。其中 25 个特殊 JPEG 采用原始字节直存。

## 质量说明

语义掩膜编码为：0=无效区域/ROI 外，1=云，2=太阳，3=天空。6 个掩膜存在“大面积云标注但图中仍有蓝天间隙”的一致性疑点，已保留并明确标记。详情见 `KNOWN_ANNOTATION_LIMITATIONS.md`。
